# OpenBuild IDE Website — PRD
**Overview:** Official informational site for OpenBuild IDE, an Android development environment for building Android apps on a phone. **Audience:** phone-based Android developers, indie developers, students.
**Objectives:** explain the product in seconds; stay honest about availability; keep all public URLs configurable.
**Design:** light, restrained palette (#F7F9FC / #3269E8 / #17243B), editorial type, product mockups, restrained motion.
**Structure:** announcement bar, sticky header, hero, positioning, features, workflow, build system (dark), roadmap, FAQ, final CTA, footer, 404.
**Functional:** mobile menu, native `<details>` FAQ, config-driven CTAs with safe fallbacks, scroll reveal via IntersectionObserver.
**Technical:** static HTML/CSS/JS, no dependencies, no tracking, Vercel deploy with security headers.
**SEO:** title, description, Open Graph, Twitter large card, SoftwareApplication JSON-LD (verified facts only), sitemap, robots.
**Accessibility:** semantic landmarks, keyboard focus states, reduced-motion support, status not conveyed by color alone.
**Success:** no broken links or fake downloads, no horizontal overflow at 360–1440 px, valid metadata.
**Out of scope:** backend, accounts, analytics, fake stats/testimonials, downloads before a release exists.
**Pre-launch checklist:** see README "Before public launch".
